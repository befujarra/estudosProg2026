algumas formas de personalização com css para os componentes

é possivel ter um arquivo global, e importar ele. Mais usado para estilização que sera usado em todas as paginas

é possivel fazer a estilização in line, onde se seta os estilos diretamente em cada arquivo na tag html, e com isso pode-se usar codigo css ou javascript

é possivel tambem ter um arquivo de estilação modular, onde se tem varias estilizações de css referente a um modulo e ele é importado para o que for necessario
