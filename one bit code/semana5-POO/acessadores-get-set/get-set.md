aula sobre get e set
ou getters e setters


os acessadores sao um recurso para definir a forma como acessamos uma propriedade de um objeto

com o acessador GET podemos modificar a forma como a propriedade é lida

com o acessador set, podemos modificar a forma como uma propriedade é alterada via atribuição

tambem conhecidos como getters e setters

ex: uma classe possui uma propriedade que necessita de uma verificação antes de ter o seu valor modificado

uma classe possui uma propriedade privada que necessita de um acessador publico somente para leitura
