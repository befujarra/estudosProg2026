POO é um paradigma de programação, ou seja, um conjunto de conceitos e recursos de linguagem que guiam a forma como programar.

Tem como peça central os objetos e a forma como eles se comunicam

os objetos podem conter dados (atributos) e código (métodos)

classes e instancias

class sao comno fabrica de objetos a partir de uma forma

instancias sao os objetos criados a partir da classe
