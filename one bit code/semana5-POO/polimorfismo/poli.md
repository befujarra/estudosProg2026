anotações sobre polimorfismo

resumidamente é a sobrescrita de metodos

um objeto assumir diferentes formas

a classe filha herda a classe pai

pega o metodo do pai
e faz alterações


por exmeplo



veiculo com metodo move


a classe filha navio

herda da classe pai o metodo Move


porem o metodo Move tem alterações por navio navega, o que tambem é se mover


entao a classe navio, herda o metodo do pai, porem segue seu proprio metodo com base nele
