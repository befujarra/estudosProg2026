associacao


uma associação é um relacionamento entre classes que permite que uma instancia de uma classe faça a outra realizar uma ação
é como dizer para aplicação que um objeto de um tipo esta conectado, relacionado a outro objeto de outro tipo

exemplo

objetos da classe Person possuem um atributo que é um objeto da classe Address

objetos de uma classe Product possuem um atributo que é um array de objetos da classe Category


associação é voce referenciar atributos, propriedades de uma classe na outra

class pessoa possui uma propriedade que referencia a classe endereço

assim vc cria padroes de objetos, usa a instancia pra criar novos objetos com esse padrao, e pode referenciar eles como campo pra um objeto maior
