//usando mpx


npm é um gerenciador de pacotes
usado para instalar, gerenciar e compartilhar pacotes de software

ele executa scripts e comandos globais ou locais 
que podem ser encontrados no arquivo package.json
ou na pasta .bin 

ele executa a tag scripts do arquivo package.json
usando o comando npm run <nome_do_script>

npm run
npm run pode ser usado se o script estiver no package.json
por exemplo start, dev, build, test

npm run start 
npm run dev
npm run build
npm run test
