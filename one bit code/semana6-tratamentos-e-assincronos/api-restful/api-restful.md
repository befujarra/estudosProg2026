primeiro o que é uma API

API - application proggraming interface
se refere ao conjunto de definições e protocolos pelo qual conseguimnos programar nossas aplicações

é um conjunto ja existente ha muito tempo na programação, mas hoje é utilizado muito para se referir aos serviços de back end

Exemplos 
DOM que aprendemos é uma forma de API, nmos ajudando a interagir com elementos do documento
 
quando usamos uma bilbioteca ou frame work, podemos dizer que ee tem suas proprias APIS, ou seja, as Formas especificas como os usasmos para programar as aplicações 

Apis Rest nos fornecem padroes para criar formas de se comunicar com um servidor



o que é rest e restfull

Rest significa respresentational state transfer

é um conjunto de restrições de arquitetura que visa organizar a comunicação entre cliente e servidor

uma api restful nada mais é do que uma API que segue a arquitetura REST


Quando um cliente faz uma requisição usando api restful ela responde transferindo uma representação do estado do recurso que foi requisitado
